# 💎 PUBG Mobile UC Shop Bot

Телеграм-бот для автоматизированной продажи игровой валюты (UC) в PUBG Mobile. 

### ✨ Основной функционал:
* 🛒 **Магазин:** Удобная витрина с паками UC.
* 👤 **Профиль:** Сохранение Player ID и просмотр баланса.
* 🕒 **График работы:** Автоматическое уведомление о статусе админа (учеба/сеть).
* 📸 **Оплата:** Ручное подтверждение заказов по скриншотам чеков.
* 📢 **Админ-панель:** Рассылка сообщений всем пользователям.

### 🛠 Технологии:
* **Python 3.10+**
* **Aiogram 3.x** (фреймворк для бота)
* **Aiosqlite** (база данных пользователей)
* **Pytz** (управление часовыми поясами МСК)

### 🚀 Запуск:
1. Установить зависимости: `pip install -r requirements.txt`
2. Настроить токен и ID админа в `config.py`
3. Запустить: `python main.py`
